## 자격증명 연결

CloudTrail의 자격증명 전환과 자원 접근을 그래프로 연결하는 연구입니다. [연구 설명과 재현 절차](../credential-linking/README.md), [논문 표와 결과 파일의 대응](../credential-linking/README.md#논문-표와-파일), [기존 인용 정보](../credential-linking/README.md#인용)를 함께 확인할 수 있습니다.

위 제목과 학회·연도는 기존 연구 README에 기재된 정보입니다. 원문을 등록할 때 최종 제목, 저자, 학회, 연도 및 DOI·공개 링크를 확인해 보완합니다.

## 로그 삭제

로그 삭제를 주제로 작성한 논문입니다. 정확한 제목, 서지 정보, 공개 원문 및 논문에 대응하는 최종 코드·실험 결과를 추가할 예정입니다. 현재 `log-deletion/`은 비워두었습니다.

## 원문을 추가할 위치

| 파일 | 내용 |
| --- | --- |
| `credential-linking.pdf` | 자격증명 연결 논문 원문 |
| `log-deletion.pdf` | 로그 삭제 논문 원문 |

PDF가 준비되면 이 폴더에 추가하고, 이 목록과 [프로젝트 첫 화면](../README.md)의 원문 칸에 링크합니다. DOI나 학회 공개 페이지가 있으면 해당 링크도 함께 기록합니다.
