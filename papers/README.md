## 자격증명 연결

**자격증명 흐름과 자원 접근을 연결하는 CloudTrail 침해 조사 그래프**

*A CloudTrail Incident Investigation Graph Linking Credential Flows and Resource Access*

CloudTrail의 자격증명 전환과 자원 접근을 그래프로 연결하는 연구입니다. [논문 원문](credential-linking.pdf), [연구 설명과 재현 절차](../credential-linking/README.md), [논문 표와 결과 파일의 대응](../credential-linking/README.md#논문-표와-파일), [인용 정보](../credential-linking/README.md#인용)를 함께 확인할 수 있습니다.

## 로그 삭제·관측 공백

**CloudTrail 관측 공백 환경에서 AWS 인프라 상태 변화 기반 그래프 추적 모델**

*A Graph-Based Tracking Model for AWS Infrastructure State Changes under Cloudtrail Observation Gaps*

[논문 원문](log-deletion.pdf)은 CloudTrail 수집이 중지되거나 기록이 삭제된 관측 공백에서, 인프라의 과거·현재 상태 차이를 그래프로 연결해 변경 행위를 추적하는 연구를 다룹니다.

원문은 등록했으며, 논문에 대응하는 최종 코드와 실험 결과를 추가할 예정입니다. `log-deletion/`은 해당 자료가 준비될 때까지 비워둡니다.
