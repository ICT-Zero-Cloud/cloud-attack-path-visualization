# 자격증명 연구의 이전 자료

현재 재현용 코드는 [main 브랜치](https://github.com/ICT-Zero-Cloud/cloud-attack-path-visualization/tree/main)에 있습니다. 이 폴더는 최종 코드 이전에 수행한 분석과 모델링을 보관합니다.

| 경로 | 내용 |
| --- | --- |
| [`graph-modeling/`](graph-modeling/README.md) | 이벤트·주체·자격증명 모델, 파서, Neo4j 적재와 질의 |
| [`normalization/`](normalization/README.md) | 정규화 설계, 노트북, 생성된 CSV |
| [`lineage/`](lineage/README.md) | 세션 생애주기와 자격증명 계보 시각화 |
| [`experiments/lateral-movement/`](experiments/lateral-movement/AWS_Lateral_Movement_Test_Report.md) | EC2 횡적 이동 실험과 그래프 이미지 |
| [`drafts/`](drafts/README.md) | 초기 논문 초안과 실험 보강 메모 |

공통 시나리오·로그는 [datasets](../datasets/README.md), 로그 수집 무력화 자료는 [log-deletion](../log-deletion/README.md)에 있습니다.
